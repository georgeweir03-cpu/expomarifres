# Cambios v4 – cómo aplicarlos
1. Respaldo: en GitHub crea la rama `respaldo-v3` desde `main`.
2. Sube el contenido de esta carpeta a una rama nueva (`rediseno-v4`) respetando carpetas. Elimina del repositorio: `src/v3.css`, `src/images.js`, `README-CAMBIOS-V3.md`, `public/img/hero.webp` y los `.jpg` de `public/img/`.
3. Vercel generará una vista previa de la rama. Revísala en escritorio, tablet y móvil antes de fusionar a `main`.
4. Configura `VITE_CONTACT_EMAIL` y `VITE_CONTACT_WHATSAPP` en Vercel.
